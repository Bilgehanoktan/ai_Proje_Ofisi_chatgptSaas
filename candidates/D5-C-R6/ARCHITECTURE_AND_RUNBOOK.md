## Problem and design
R5 PG03 observed a durable row by a separate connection after an expiry-crossing deferred trigger, despite a valid pre-COMMIT sample. PG04's deferred check rejected the probe and transport returned UNKNOWN with zero rows. It is not proof of an absolute commit deadline. PostgreSQL 17 constraint triggers run as part of the transaction; pre-COMMIT, timeouts and later commit timestamps cannot independently prove the required durable linearization deadline. D5-D OWNER_CONTRACT strict expiry remains unchanged. No grace period, lease extension, 2PC, timeout-only acceptance, after-commit compensating delete or retry is introduced.
