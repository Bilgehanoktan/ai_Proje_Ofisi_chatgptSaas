## Trust and limits

Initial QUEUED head is a pinned starting point; older pre-admission events intentionally outside this profile and rejected if present. Max 1000 commands including admission, per-run exact set; foreign run rows and unreferenced global fences are not a global audit. Budget comparison checks pinned reservation/settlement and monotonic historical revisions, not current shared pool balance or economic ledger. D0 failure only, no success/stop/UNKNOWN authority.
