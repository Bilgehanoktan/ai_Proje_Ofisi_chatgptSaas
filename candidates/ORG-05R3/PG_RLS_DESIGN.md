Prefer a reviewed shared trusted principal/scope resolver from D3, not a second production identity authority. For disposable fixture only, scope mapping keyed by authenticated database session_user with one explicit triple per login; protect mapping from all runtime writes and prevent caller SET/SET ROLE from altering identity. No GUC-only policy. Session identity, pooling/reset and revocation need independent review.
- Enable AND FORCE RLS on each of the 12 organization tables; default deny when no verified scope mapping. SELECT USING same triple; INSERT WITH CHECK same triple (writer only); head UPDATE USING and WITH CHECK same triple; other UPDATE and DELETE denied by privilege and policy. Policy function only if reviewed, fixed search_path, fully qualified relations, least privileges and no public EXECUTE. No grants are issued here.
- Lock order: scope head first, then project history head/sequence; use transaction-level CAS and unique indexes; re-read current organization revision, validated team and pinned task before atomic proposal+notice write. PostgreSQL implementation needs explicit genesis serialization (unique conflict/retry as HOLD, not automatic dispatch), SQLSTATE and two-connection tests. No automatic retries after uncertain outcomes.
