## Architecture, schema and ownership
SQLite D0 disposable file only, eight tables: org_revision, org_head, org_unit, org_position, org_definition_ref, org_instance_ref, org_binding, org_notice. Composite tenant/company/environment/revision keys, same-scope foreign keys, role-compatible bindings, one seat/instance binding per revision, unique sequence, deferred reporting/unit parents. Existing guard validates cycles and role vocabulary before writing; readback reconstructs and verifies the staffing hash, scope-specific persisted revision hash and notice. Seven immutable tables protected by UPDATE/DELETE triggers created by initialize(); direct INSERT or privileged trigger removal is not a security boundary. The head is mutable via CAS. Old revisions retained; full audit uses separately retained expected head. record() atomically records snapshot/notice/head under BEGIN IMMEDIATE and rolls back errors; no business operation is authorized. Org scope environment included in persistence digest, not the legacy Staffing digest. Scope accepts only synthetic- labels and two local test environments; instance references must be demo- labels, not authenticated identities. No user data, grants, principal creation or active worker. Agent Catalog/Runtime owns definition/instance lifecycle (proposed); Organization owns structure, reporting and position bindings; IAM/Policy owns principals and access; Runtime owns runs; Event Store owns canonical events; Office owns geometry. Owner receipts remain HOLD. Temporary ProjectTeam/handoff history remains in-memory in inherited operations.py; separate durable design pending.
