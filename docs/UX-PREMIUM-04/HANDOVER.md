## Architecture and source changes
- `premiumTraffic.ts`: incremental weighted A* joint state planner, 2–4 actors, one move per edge, occupancy and fixed obstacle constraints; deterministic heap tie; 20,000 stored-state cap, 96 popped states per tick (up to 256 explicitly); `LIMIT` is not proof of impossibility. No optimality or global liveness claim. Search input copied; walkability predicate and fixed set assumed stable during search. Browser visual motion only.
- `premiumModel.ts`: when normal reserved-cell routing stalls and no actor is in flight, launch joint planning for all current actors, including parked ones. Freeze visual motion while planning, execute one edge at a time after checking occupancy and adjacency. Valid local command cancels old search/recovery; mid-edge command remains rejected. Report `TRAFFIC_PLANNING`, `COOPERATIVE_ESCAPE`, `WAIT_SEARCH_LIMIT`, `WAIT_BLOCKED`; bounded retry after 30 ticks. Livelock with ongoing movement and swept-body collision remain open. Old `pairEscape` helper and tests retained for compatibility; no longer used by scheduler.
- `premiumOfficeV0.ts`: `inspectGeometryGap` inspects the exact historical fixture and displays two coordinate spaces side-by-side; rows are diagnostics, not a mapping/authorization. Invalid source/coordinates => empty rows. Source `draft-hybrid-floor-1`; backend `layout-d3-demo` 6×6; decorative 12×10. Five blocking reasons: owner, layout revision, policy/witness epochs, instance/lease/task proof, trusted freshness. `placement`, `taskBinding`, `authoritative` always false. No new OfficeV0 schema, no live adapter. Source pins: fixture `ac57b926e701196c7507a396aa868ce5e8bd5806`, layout.py `cf47623d303d21aed11eb5ee69b66a757c6a5d18`, freshness.py `b988420248dc3591aa0180a23bdf32b74d7cb3b6`, crosswalk 55 `c9c648733f3b2a04aaef1b99aebedff2e4cd7d2a`, workbench parser `d8d0cf4ce765651bd5490df1482a92ff0c668943`.
